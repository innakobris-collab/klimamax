# KlimaMax — Klimatechnik NRW

Statische Landingpage (One-Page) für KlimaMax Klimatechnik, Nordrhein-Westfalen.
Luxury-Design (crème/braun/messing), Deutsch, mobile-first.

## Struktur
- `index.html` — komplette Seite (inline CSS/JS, keine Build-Schritte)
- `images/` — Fotos (hero.jpg, aussen.jpg, raum.jpg)

## Deployment
Reine Statik — kein Build nötig. Vercel/Netlify erkennen `index.html` automatisch.
